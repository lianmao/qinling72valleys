# 秦岭七十二峪 · 互动导游与出游决策地图

秦岭北麓（渭南 / 西安 / 宝鸡）七十二峪的数字化名录、露营配套看板、农家乐与安全状态查询。
纯静态 Jamstack 应用，零后端，高德地图 JS API v2.0 打点 + 点聚合 + 一键导航。

## ⚠️ 数据可信度声明（开发期）

仓库内 `PRD.md` 第 3 节的名录与坐标为**未经核实的初稿**（区域计数存在矛盾、坐标疑似等步长生成）。
在逐条核实并标注来源之前，不得作为导航坐标发布。字段级别将引入：

```
source        // 数据来源（官方通告 / 实地 / 高德 POI / 待核实）
verified_at   // 核实时间
confidence    // high / medium / unverified
```

未核实字段前端一律显示「待核实」，不得默认显示为「允许过夜 / 绿灯开放」。
