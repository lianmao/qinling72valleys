## 2. 复核方法（可复现）

实体级复核用「精确短语检索 + 属地词」在公开搜索引擎上取证，判据：
`found_local` 命中且属地相符 / `found_foreign` 仅命中外省同名 / `not_found` 无任何命中 / `blocked` 通道不可用。

| 通道 | 结果 | 证据 |

## 4. 已按建议落地的处理

1. **来源分级**（`provenance`）：`prd_listed`（名称字面出现在用户交付的原始 PRD）/ `derived`（文档只有描述、名称由本站归纳）。
   界面在归纳条目上打「整理」标签，并给出口径说明。
2. **农家乐名单降级**：未取得公开踪迹的店名一律收进详情页折叠区，标题写明「不作为推荐」，
   并注明"来自需求文档初稿、公开检索未找到对应实体"。取得 `found_local` 证据的条目会自动移到上方「公开可查」区。
3. **不给主观机位、不给联系方式**：打卡点只保留 `basis`（文史/地标）机位；全站无电话字段。
